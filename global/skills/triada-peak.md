# Habilidad: Modelado 3D de Precisión y Tríada Peak

## Principios
- Simetría y calibración geométrica estricta para impresión 3D FDM.
- Tolerancias mecánicas: mínimo 0.2 mm para holguras de encaje macho-hembra.
- Orientación de capas y refuerzos estructurales en cantos y esquinas críticas.
- Generación de código Python reproducible (utilizando bibliotecas paramétricas como CadQuery / OpenSCAD / Trimesh / Numpy).
